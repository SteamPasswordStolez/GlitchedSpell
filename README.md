# GlitchedSpell

GlitchedSpell의 소개 사이트입니다. 2026년 10월 시작한 독립 FPS 게임 개발 프로젝트로, 웹 AAA 게임을 목표로 개발하며 대표작 [Strikegy](https://strikegy.xyz)를 소개합니다. 사이트의 시작 시점 표기는 개발 프로젝트의 시작을 의미합니다.

## 실행

Node.js 22.12 이상을 권장합니다 (기존 Vite 7 기반).

```sh
npm ci
npm run dev
```

```sh
npm test
npm run build
npm run preview
```

`dist/`가 정적 배포 산출물입니다. 기존 `CNAME`도 Vite 빌드에 포함됩니다. 저장소의 main 브랜치와 기존 게임 프로토타입을 보존하며, 소개 사이트는 `index.html`, 프로토타입 로비는 `lobby.html`, 게임은 `game.html`에서 열립니다.

## 다국어

한국어(`ko`), 영어(`en`), 스페인어(`es`), 프랑스어(`fr`), 독일어(`de`), 일본어(`ja`)를 지원합니다. 상단 선택기로 언어를 변경하면 본문, 메뉴, 이미지 대체 텍스트, 접근성 레이블, 문서 제목과 메타 설명이 함께 바뀝니다.

- 공유 URL 예시: `/?lang=ko`, `/?lang=en`, `/?lang=ja`
- 우선순위: 지원되는 URL 언어 → 저장된 언어 → 브라우저 언어 → 영어
- 번역 수정: `src/studio/locales.js`
- 브라우저 저장소를 사용할 수 없어도 언어 선택은 작동합니다.

## 디자인과 리소스

반응형 레이아웃, 모바일 메뉴, 키보드 탐색, 동작 줄이기 설정을 지원합니다. 전장 그래픽은 자체 제작 SVG 콘셉트 일러스트이며 실제 게임 화면이 아닙니다. `npm run art`로 재생성할 수 있습니다. Google Fonts를 사용하며 연결이 제한되면 시스템 글꼴로 대체됩니다.

`npm test`는 번역 누락, 언어 선택 우선순위, Strikegy 링크와 로컬 리소스를 검사합니다. 기존 게임 프로토타입은 회사 소개 사이트의 다국어 범위에 포함되지 않습니다.
